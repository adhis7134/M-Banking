\# 💳 M-Banking



A web-based mobile banking application prototype developed using HTML, CSS, JavaScript, Python, and SQLite.



\## 📖 About The Project



M-Banking is designed to simulate modern digital banking services. The application provides an intuitive user interface for managing accounts, viewing balances, performing transfers, and reviewing transaction history.



This project was developed for educational and portfolio purposes as part of UI/UX Design and Web Development learning.



\---



\## ✨ Features



\- User Dashboard

\- Account Balance Information

\- Transfer Simulation

\- Transaction History

\- Responsive Interface

\- SQLite Database Integration

\- Python Backend Support

\## 🚀 Installation



Clone repository:



```bash

git clone https://github.com/adhis7134/M-Banking.git

```



Open project directory:



```bash

cd M-Banking

```



Run backend server:



```bash

python server.py

```



Open browser:



```text

http://localhost:5000

```
